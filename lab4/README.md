# Лабораторная 4

Рисование на QML:
1) Рисование мышью на холсте.
2) Холст автоматически сохраняется в PNG каждые 5 секунд (запись атомарная: сначала во временный файл, потом замена).
3) Можно загрузить последний сохранённый холст и продолжить рисовать.

**Папку сохранения и интервал автосохранения можно изменить в .env**
