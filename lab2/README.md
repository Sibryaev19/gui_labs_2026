# Лабораторная 2

Конвертер валют (доллар / евро / рубль):
1) При изменении любого поля два остальных пересчитываются автоматически (сигналы-слоты).
2) Кнопка "обновить курс" подтягивает рыночный курс forex.
3) Если сеть недоступна, показывается ошибка, а старый курс сохраняется; при первом запуске курс берётся из .env

**Изменить курс по умолчанию можно в .env**
