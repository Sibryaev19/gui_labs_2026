# Лабораторная 3

Просмотр БД SQLite:
1) Кнопка "Выбрать БД" открывает диалог выбора файла БД, "Connect" подключается к ней.
2) После подключения выводится список таблиц; выбор таблицы показывает её содержимое.
3) Для выбранной колонки выводится статистика (тип, количество, min/max/среднее).
4) Кнопка "SQL query" выполняет произвольный SQL-запрос.
5) Результаты запросов открываются во вкладках, вкладки можно закрывать; "Disconnect" отключается от БД.

**Путь к БД по умолчанию можно изменить в .env**
